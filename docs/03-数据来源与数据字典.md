## 5. 数据局限与分析适用边界

本节记录选型文档已指出的局限，以及首份文件实测观察到的质量特征。

| 已知局限与实测特征 | 对分析使用的约束 |
| --- | --- |
| 不含快递运费金额字段 | 支持方向以单量、履约时效、作业负荷和人员作业表现为主；不据此计算营收、运费或利润 |
| 隐去快递员姓名及具体小区文字名称，保留编号 | 分析对象以脱敏标识区分；不能将编号解释为真实姓名或直接还原小区名称 |
| 时间戳隐去具体年份（格式 `MM-DD HH:MM:SS`，日期列 `ds` 为 `MMDD`） | 原始接入层按源文本保存，不自行补年份；后续逻辑／物理建模转换时须明确年份处理规则 |
| 派件文件 `accept_gps_lng`／`accept_gps_lat` 存在 `"nan"` 文本缺失（吉林派件占 955／31,415 行） | 原始接入层原样保留 `"nan"` 字符串；后续清洗转换层（DWD）再统一将 `"nan"` 转换为数据库 `NULL` |
| 派件文件 `delivery_jl.csv` 不含预约时间窗字段（`time_window_start`／`end`） | 预约时间窗准时／超时率指标需结合包含预约时间窗的揽收子集（`LaDe-P`）核定口径 |
| 经纬度经过隐私微扰，选型文档记载约为 10 米半径 | 空间位置不能视为原始精确位置；行政区或街道归属需要另行核查，不能承诺无损还原 |
| 来源为连续 6 个月的静态归档数据 | 不能描述为项目已接入持续产生的实时业务数据 |
