## 1. 来源与使用边界

当前数据源为 [Kaggle H&M Personalized Fashion Recommendations 竞赛](https://www.kaggle.com/competitions/h-and-m-personalized-fashion-recommendations/)。竞赛说明称训练数据提供客户跨时间购买历史及客户、商品元数据；完全相同的交易行可能表示同一商品的多次购买。竞赛规则将数据用途限定为非商业用途，包括学术研究和教育。本项目以商业经营问题作为分析设计视角，但数据实际只用于课程教育，不在仓库中发布原始数据或对外分发。

本地原始文件位于 `data/raw/hm_recommendations/`，由 Git 忽略。来源访问条件、许可记录和文件校验见 [数据源选取](12-数据源选取.md) 与 [下载校验清单](附件-数据下载校验清单.csv)。

## 3. 字段说明

### 3.1 购买记录

| 字段 | 类型 / 含义 | 质量与口径 |
| --- | --- | --- |
| `t_dat` | 日期 | 2018-09-20 至 2020-09-22；日期范围内每天均有记录 |
| `customer_id` | 客户伪名标识 | 交易行均匹配客户表；只用于内部关联，不尝试反推身份 |
| `article_id` | 商品款式标识 | 交易行均匹配商品目录；最大源值 959461001，适合 Doris `INT` |
| `price` | 源价格数值 | 非空且大于 0；观察范围 0.00001694915254237288 至 0.5915254237288136。没有经核实的币种或金额定义，不命名为销售额、营收或实收金额 |
| `sales_channel_id` | 渠道编码 | 本地观察到编码 1 和 2；业务名称待权威定义核实，暂按编码展示 |

竞赛说明表明完全相同的交易行可能对应多次购买。不得按整行去重；一行按一件商品购买记录计，但不把行数称为订单数。完整价格、渠道统计见质量盘点附件。

### 3.2 客户属性

| 字段 | 观察结果 | 使用边界 |
| --- | --- | --- |
| `customer_id` | 1,371,980 个唯一值，重复键 0 行 | 客户关联键 |
| `FN` | 895,050 行为空（65.24%）；非空值为 `1.0` | 保留源标记和空值，不把空值转换为否 |
| `Active` | 907,576 行为空（66.15%）；非空值为 `1.0` | 保留源标记和空值；确切业务定义和有效时点待核实 |
| `club_member_status` | 空值 6,062 行（0.44%）；观察到 `ACTIVE`、`PRE-CREATE`、`LEFT CLUB` | 状态来自无时间戳快照，不回填成历史时点状态 |
| `fashion_news_frequency` | 空值 16,009 行（1.17%）；观察到 `NONE`、`Regularly`、`Monthly` 及大小写变体 | 缺失和源值按类别保留；标准化需另记规则 |
| `age` | 空值 15,861 行（1.16%）；非空观察值 16 至 99 | 仅聚合分组；不作个体画像或定向，不解释为交易发生时年龄 |
| `postal_code` | 无空值，最长 64 字符 | 项目现有来源材料将其标记为哈希值；不反推地理区域或用于地图，不进入首版分析维度表 |

客户数据是静态属性快照，没有属性生效日期。将其连接至 2018—2020 历史购买记录只能用于描述性分群，不能视作购买发生时的历史属性。

### 3.3 商品属性

商品表包含 `article_id`、`product_code`、商品名称、商品类型和组、图案和颜色、部门、`index`、`section`、服装组及描述字段。完整字段按源列序登记在字段清单。

全表 105,542 个 `article_id` 唯一，重复键 0 行；`detail_desc` 有 416 行空值（0.39%），最大文本长度 764 字符。目录中有 995 个商品款式没有出现在训练购买记录中，这只表示观察窗口未发现购买，不代表商品无需求、缺货或不可售。

商品目录没有生效日期、上下架、库存、价格历史或曝光信息。分类字段作为描述性属性分别使用；尚未证实的字段之间不强行构造父子层级。

## 4. 首轮数据质量结论

- 交易五个字段均无空值；日期和价格均可解析，价格非正行数为 0。
- 交易中 1,362,281 个不同客户和 104,547 个不同商品；客户与商品外键未匹配行均为 0。
- 客户和商品维度键均唯一；交易日期连续覆盖 734 天。
- 渠道编码 1 占购买记录 29.60%，编码 2 占 70.40%；该比例只表示购买记录构成，不能推断渠道名称或转换效率。
- 客户属性 `FN`、`Active` 缺失较多；分析时保留未知分组并显示有效覆盖率。
- 源价格仅作相对数值分布比较。禁止求和生成营收；缺少库存和曝光也意味着不能计算售罄率或转化率。
- 完全相同的交易行按竞赛说明作为可能的多件购买保留；没有把它们当作质量错误或合并。

当前数据质量结论只覆盖文件结构、空值、基础数值解析、主键唯一、交易外键覆盖、日期范围及有限值域。没有证据支持订单、退货、成本、库存、上架状态或营销效果分析。

## 5. 外部定义与后续核查
