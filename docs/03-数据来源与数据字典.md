## 1. 来源与访问

当前来源为 [Kaggle H&M Personalized Fashion Recommendations 竞赛](https://www.kaggle.com/competitions/h-and-m-personalized-fashion-recommendations/)。官方说明该竞赛利用过往交易及客户、商品元数据开展个性化推荐。竞赛数据页要求登录并接受[竞赛规则](https://www.kaggle.com/c/h-and-m-personalized-fashion-recommendations/rules)后访问。

规则允许非商业使用，包括学术研究和教育；本项目数据只用于课程作业。原始数据不提交 Git、不另行公开分发。Kaggle CLI 下载已成功；文件完整性与列结构已在本地检查。以下字段以实际文件为准，空值比例、重复记录、值域和主外键覆盖率尚未盘点。

## 3. 预期字段

### 3.1 交易 `transactions_train.csv`

已验证字段：`t_dat`（交易日期）、`customer_id`（客户键）、`article_id`（商品键）、`price`（源价格数值）、`sales_channel_id`（销售渠道编码）。共 31,788,324 行；日期范围为 2018-09-20 至 2020-09-22；列数与预期一致，没有发现列数异常行。

### 3.2 客户 `customers.csv`

已验证字段：`customer_id`、`FN`、`Active`、`club_member_status`、`fashion_news_frequency`、`age`、`postal_code`。共 1,371,980 行，列数与预期一致。客户字段的空值比例、编码含义与可用于分群的口径待检查。`customer_id` 为源标识，不应尝试反推真实身份。

### 3.3 商品 `articles.csv`

已验证 25 个字段，包括商品标识与品名、商品类型与分组、图案与颜色、部门、商品索引组、版型类别及细节描述；共 105,542 行。完整字段名与原始列序见[字段清单](附件-字段清单.csv)。

## 4. 已知限制与待核查项

- 旧选型材料指出客户邮编为哈希值。本轮尚未核对本地列值，不使用该字段做行政区或地图分析。
- 旧选型材料指出 `price` 为缩放值。本轮尚未复核数值与定义，不把它当作真实币种、含税销售额或可直接计算的营收。
- 竞赛训练交易是指定时间范围的历史样本，实际日期为 2018-09-20 至 2020-09-22；重复交易、空值、ID 关联覆盖率和日期连续性待进一步盘点。
- 退货、折扣、库存和门店实体是否包含于这些源表尚待字段核查；不得把源中没有的业务状态推断出来。
- 图片和 `sample_submission.csv` 暂不进入首批数据范围，是否需要由 W04 需求决定。
