# 技术栈与版本

最后更新：2026-11-12（Asia/Shanghai）

## 1. 已确认的技术路线

技术路线保持 Pixi + Python、Apache Doris、Streamlit、Metabase、PostgreSQL 与 Docker Compose。Pixi 管理 Python 环境与任务；Python 负责通过 Kaggle CLI 获取数据、核验和处理 CSV；Doris 为分析数仓；Streamlit 提供定制界面；Metabase 提供自助查询和看板；PostgreSQL 保存 Metabase 应用配置；Docker Compose 管理共享服务。
