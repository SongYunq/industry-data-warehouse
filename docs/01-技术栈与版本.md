# 技术栈与版本

最后更新：2026-11-12（Asia/Shanghai）

## 1. 已确认的技术路线

本项目采用以下职责分工：Pixi 管理 Python 环境与任务；Python 负责文件获取、读取和处理；Apache Doris 作为分析数仓；Streamlit 提供定制交互界面；Metabase 提供自助查询与看板；PostgreSQL 保存 Metabase 应用配置；Docker Compose 管理服务。

数据源工具使用既有 `httpx` 发起 HTTP 请求，使用 Python 标准库读取 GZIP CSV、CSV 和 GeoJSON。当前阶段未新增 Python 依赖。
