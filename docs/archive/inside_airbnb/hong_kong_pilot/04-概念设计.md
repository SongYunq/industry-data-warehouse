# 香港先锋概念设计

- 状态：扩展版首稿已实现
- 最后更新：2026-11-12（Asia/Shanghai）

## 业务对象

- **房源**：Inside Airbnb 在某一期来源快照中记录的公开挂牌，以 `listing_id` 标识。
- **房源快照**：房源在一个采集日期观察到的属性；房源是否在其他期出现不构成退市结论。
- **房东快照**：一个房东在一个来源采集期公开展示的属性，不永久化超赞或验证状态。
- **街区、房型、房屋类型**：来源提供的类别及区域对象；以街区边界辅助汇总，不将其解释为政府行政区界。
- **日历房态**：一个快照里未来某日对某个房源显示的可订状态；不可订可能是预订或房东封锁。
- **评论月汇总**：最新累积评论导出按评论日期汇总的月份统计；不是订单或入住记录。

## 分析过程与关系

房源快照连接城市、快照、街区、房型、房屋类型和对应的房东快照。日历汇总按快照、日历日、街区、房型及房屋类型记录状态计数。评论月汇总按城市和评论月份记录评论量，使用日期维度分析时间。维度均与房事实通过自然键连接。

## 边界

本模型描述公开挂牌、公开日历和评论活动，不构造订单、入住、付款或营收对象。街区地图使用来源边界，不展示单房源坐标。房东标识只用于快照去重和分析连接，不在看板呈现。
