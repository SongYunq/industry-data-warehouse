# 香港先锋技术栈与版本

- 状态：沿用项目已选路线；香港专用数据库尚未实际构建
- 最后更新：2026-11-12（Asia/Shanghai）

## 工具职责

| 工具 | 本先锋用途 | 版本状态 |
| --- | --- | --- |
| Pixi + Python | 锁定依赖并运行数据命令 | 项目锁文件中记录版本；环境已可运行 |
| Apache Doris | 存储房源快照事实和街区边界维度 | Compose 声明 FE/BE `4.0.8`；先锋库和两表已建，数据写入被 BE 内存低水位阻止 |
| Streamlit | 交互式香港市场观察看板 | `pixi.toml` 声明 `1.67.0`；本地预览采用同一项目环境 |
| PyMySQL | Python 通过 MySQL 协议读写 Doris | 项目依赖已声明；与本机 Doris 的联通待验证 |
| Docker Compose | 启停共享 Doris/Metabase/PostgreSQL 服务 | 复用 `deploy/compose.yaml`；本次 Docker CLI 状态检查被 socket 权限拒绝，没有重启或停止共享容器 |

## 运行方式

- `pixi run dashboard`：启动香港先锋 Streamlit 看板。
- `pixi run data-load-hong-kong`：创建 `hk_airbnb_pilot` 数据库和两张先锋表，并写入四期房源快照与街区边界。
- 看板默认 `auto`：先尝试 Doris，连接失败时转本地预览；`HK_PILOT_DATA_MODE=warehouse` 强制 Doris，`local` 强制本地文件。

正式版 V1 的技术基线未在本次修改；本文件只记录香港先锋的实际使用范围与验证状态。
