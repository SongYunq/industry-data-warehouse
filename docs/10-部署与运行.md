## 可用 Pixi 任务

| 任务 | 用途 |
| --- | --- |
| `pixi run data-fetch` | 按数据清单获取或复用原始文件 |
| `pixi run data-check` | 按字节数和 SHA-256 核验文件 |
| `pixi run data-inspect` | 盘点 CSV、GZIP CSV 与 GeoJSON 结构 |
| `pixi run dashboard` | 启动 Streamlit 原始文件盘点页 |
| `pixi run services-up` | 启动 Compose 服务并等待 Doris 集群就绪 |
| `pixi run services-down` | 停止 Compose 服务，不删除具名数据卷 |
| `pixi run services-status` | 查看 Compose 和 Doris 状态 |

本文件的首次部署步骤、配置逐项说明和故障处理在完成 W04—W08 的设计与验证后补充。当前整体进度见 [工作内容与进度](00-工作内容与进度.md)。
