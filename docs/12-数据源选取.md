## 1. 当前决定

用户于 2026-11-12 决定将当前来源从 Inside Airbnb 改为 Kaggle **H&M Personalized Fashion Recommendations** 竞赛数据。技术路线保持 Pixi + Python、Apache Doris、Streamlit、Metabase、PostgreSQL 和 Docker Compose。

W03 首批文件为 `transactions_train.csv`、`customers.csv`、`articles.csv`。`sample_submission.csv` 与商品图片暂不进入首版数仓。

## 2. 来源、许可与访问条件

- 来源：[Kaggle H&M 竞赛数据页](https://www.kaggle.com/competitions/h-and-m-personalized-fashion-recommendations/data)。官方将任务描述为根据历史购买及客户、商品元数据预测客户后续购买。
- [竞赛规则](https://www.kaggle.com/c/h-and-m-personalized-fashion-recommendations/rules) 将竞赛数据使用限制为非商业用途，包括竞赛参与、学术研究和教育。项目可用零售商业分析问题作为课程设计视角，但不可将数据或项目用于商业部署、商业分析服务或对外分发。
- 数据访问需先登录 Kaggle 并接受规则，再使用 Kaggle CLI。三份文件已按此访问条件下载；`customers.csv` 首次下载连接中断后单文件重试成功。
- Kaggle 身份凭据由个人 CLI 配置管理；不存入仓库、项目 `.env`、日志、清单或示例文件。

## 3. 数据能力与已核查限制

| 能力 | 本地核查结果 | 限制 |
| --- | --- | --- |
| 购买记录 | 31,788,324 行，2018-09-20 至 2020-09-22，734 个连续自然日 | 同一客户同日多行没有订单 ID；完全相同行可能代表多次购买，必须保留 |
| 客户属性 | 1,371,980 行；`customer_id` 唯一 | 属性没有生效日期；`FN`、`Active` 分别有 65.24%、66.15% 空值 |
| 商品目录 | 105,542 行；`article_id` 唯一 | 没有库存、上架或曝光历史；训练期无购买记录不等于缺货或无需求 |
| 外键 | 全部交易客户和商品键均能匹配对应维表 | 关联覆盖不提供营销触达或商品曝光口径 |
| 源价格 | 有效值范围 0.00001694915254237288 至 0.5915254237288136 | 没有经核实的货币、含税、折扣或营收定义；不以总和计算收入 |
| 渠道 | 交易中编码 1、2，购买记录占比分别为 29.60%、70.40% | 代码名未在竞赛数据说明中核实，不标注线上／线下 |
| 邮编 | 源字段存在；项目现有来源材料将其标记为哈希标识 | 不尝试地理反推；不进入首版分析维度 |

全部盘点行和分母见 [数据质量盘点](附件-数据质量盘点.csv)；文件摘要见 [下载校验清单](附件-数据下载校验清单.csv)。
