- 状态：H&M 已选为当前数据源；三份核心 CSV 下载、SHA-256 核验和结构盘点已完成
- 最后更新：2026-11-12（Asia/Shanghai）

## 1. 当前决定

用户于 2026-11-12 决定将当前数据源从 Inside Airbnb 改为 Kaggle 的 **H&M Personalized Fashion Recommendations** 竞赛数据。Pixi + Python、Apache Doris、Streamlit、Metabase、PostgreSQL 与 Docker Compose 技术路线保持不变。

W03 首批分析源文件范围定为三张核心 CSV：`transactions_train.csv`、`customers.csv`、`articles.csv`。`sample_submission.csv` 是竞赛提交模板，商品图片数据暂不纳入首批数仓文件；如果 W04 确认图片或视觉特征有具体用途，再另行决策。交易、客户和商品数据范围以 Kaggle 官方竞赛数据页当前提供文件为准。

## 2. 来源、许可与访问条件

- 来源：[H&M Personalized Fashion Recommendations 竞赛数据页](https://www.kaggle.com/competitions/h-and-m-personalized-fashion-recommendations/data)。竞赛内容由 H&M Group 发布，数据用于结合历史交易、客户和商品元数据开展个性化时尚推荐研究。
- 访问：[竞赛规则](https://www.kaggle.com/c/h-and-m-personalized-fashion-recommendations/rules)限制数据用于非商业用途，包括竞赛参与、Kaggle 论坛、学术研究和教育。课程作业范围与该用途相符；不得把本地数据再分发到代码仓库或公开镜像。
- 下载前需要 Kaggle 登录并接受竞赛规则，再通过 Kaggle CLI 完成身份验证。本轮已按此流程获取三份文件；`customers.csv` 首次下载遇到连接中断，单文件重试成功。
- 身份凭据仅由 Kaggle CLI 保存在用户个人配置目录或由 CLI 读取环境变量；不得写入仓库、`.env.example`、数据清单或日志。

## 3. 数据能力与限制

核心表关系为交易记录关联客户和商品：`transactions_train.customer_id` 对应 `customers.customer_id`，`transactions_train.article_id` 对应 `articles.article_id`。这为交易时间、商品类别和客户分群分析提供数据基础；实际指标、粒度、用户角色和验收要求留到 W04 确认。

本轮本地文件盘点结果：31,788,324 笔交易、1,371,980 名客户和 105,542 种商品。交易文件含 5 列，日期覆盖 2018-09-20 至 2020-09-22；客户文件含 7 列，商品文件含 25 列。逐文件字节数和 SHA-256 见 [下载校验清单](附件-数据下载校验清单.csv)。

旧选型记录提示 `postal_code` 经哈希处理、`price` 是缩放值而非真实币种金额。本轮尚未复核字段值域与定义，故不把邮编当作地理位置，不把 `price` 标成货币或直接换算营收。空值、重复记录和 ID 关联覆盖率也待进一步分析；W04 再决定可采用的价格指标。
