# 需求分析

- 状态：W04 扩展版商业分析需求与指标口径已形成；用户已确认商品／品类优先，客户再次购买和渠道分析为辅
- 最后更新：2026-11-12（Asia/Shanghai）

## 1. 分析目标

围绕 H&M 历史购买记录，分析“哪些款式、颜色和品类被购买”“不同客户群与渠道的购买组合有什么差异”“客户通常在第几个不同购买日后不再于观察窗内回购”。输出应支持商品组合复核、客户回购研究和渠道差异讨论。

用户确认的主题顺序为：**商品／品类表现优先；客户再次购买日与渠道构成为辅**。项目以商业经营问题作为课程设计视角，竞赛数据实际用途限于教育和学术研究；Kaggle 规则不允许商业使用或对外分发。

## 2. 建议的使用者与决策场景

| 建议角色 | 希望回答的问题 | 可支持的讨论 |
| --- | --- | --- |
| 商品／品类运营 | 哪些商品组、款式族、颜色、图案和具体商品有较高购买件数与买家覆盖？ | 复核商品组合、颜色搭配、款式族内部变体表现 |
| 会员／客户运营 | 客户第 1、2、3 个观察购买日之后，多少人在完整的 30／60／90 日窗口内再次购买？ | 找出需要进一步研究的回购间隔和客户分群 |
| 渠道运营 | 两个渠道编码的商品结构、客户重合和跨编码切换情况怎样？ | 比较渠道购买组合；在线／线下标签需先核实 |
| 经营管理 | 商品、客户和渠道构成如何随月份、季度与星期变化？ | 形成商品组合与客户经营的后续假设，不直接宣称因果或利润改善 |

以上是按数据能力设计的分析角色，不代表已有真实企业或负责人。

## 3. 分析范围

### 纳入

- 观察期为 2018-09-20 至 2020-09-22。按完整自然月比较趋势；首尾月明确标成部分月份。
- 商品：商品组、类型、服装组、`index_group`、`index`、部门、版块、`product_code` 款式族候选、`article_id` 具体变体、颜色组、主色系、明暗值和图案。
- 客户：观察窗购买客户、新客样本（观察窗首次购买，非真实拉新）、不同购买日频次、购买间隔、最近一次观察购买距数据截止日的天数、长间隔后回购，以及第 N 个购买日之后的限期再次购买。
- 客户首现月份分群：按观察期内首次记录购买的月份组成“首现月份组”，比较后续 30／60／90 日再次购买；它不是注册或真实获客月份。
- 渠道：先按源编码 1、2 比较；如果取得权威映射，再将编码解释为线上／线下。可比较渠道组合、客户重合和跨渠道切换。
- 时间：年月、季度、星期；服装季节只能按月份描述，不推断国家、气候或促销日历。
- 客户属性：年龄段、会员状态和资讯频率可作汇总分群；高空值的 `FN`、`Active` 只作可选探索并显示覆盖率。
- 源 `price` 数值分布作为辅助探索，不计算货币金额。

### 暂不支持的经营结论

- **订单与购物篮**：没有订单 ID。同日多行既可能是同单多件，也可能是多笔购买；不能计算订单数、每单件数、客单价或连带率。
- **品牌真实流失**：没有注册日期、完整的观察窗外历史和后续购买结果。可以计算第 N 个不同购买日后的“限期再次购买日率”和“窗口内未观察到回购比例”，不能断言客户放弃品牌或已经流失。
- **线上／线下结论**：`sales_channel_id` 当前只确认编码为 1、2，权威名称尚未查到；先按代码值分析，不能先验贴成线上或门店。
- **营收和盈利**：源 `price` 的货币和计算口径未确认，且无成本、税费和折扣字段；不计算营收、毛利、利润或价格弹性。
- **库存与转化**：没有库存、上架、曝光、访问和可售状态；不计算售罄率、缺货率、转化率或渠道增量。
- **同单关联／因果交叉销售**：没有购物篮和营销活动数据；相邻购买日的品类变化只描述先后顺序，不称同单连带或活动效果。
- **图片与文本自动分类**：商品描述可供后续关键词探索；图片未纳入当前数据。材料、版型、场景等文本推断只有在人工核验后才能展示为分类结果。

邮编地理反推、客户伪名键公开、个体客户定向均不纳入。

## 4. 指标口径

指标定义由本节统一维护；模型、页面和验收引用这里的公式。分析事件以不同购买日期为客户回购单位，不假设订单或到店。

| 指标 | 计算口径 | 商业解释与限制 |
| --- | --- | --- |
| 观察购买件数 | `COUNT(*)`；每条源交易行计 1 件 | Kaggle 说明相同行也可能表示同款多件购买，保留不去重；不是订单数 |
| 活跃购买客户数 | 筛选期内 `COUNT(DISTINCT customer_id)` | 表示该观察期有购买记录，不等于会员基数或当前活跃人数 |
| 商品／款式族购买占比 | 商品或 `product_code` 组的购买件数 ÷ 当前筛选范围购买件数 | `product_code` 是基于编码结构提出的款式族候选；分类冲突需保留并可下钻 `article_id` |
| 商品买家覆盖 | 商品、款式族或分类下的 `COUNT(DISTINCT customer_id)` | 衡量观察买家数，不是曝光转化或潜在需求 |
| 头部商品／款式集中度 | 当前范围购买件数排名前 10 个 `article_id` 或候选 `product_code` 的购买件数 ÷ 当前范围购买件数；另显示前 20 名作为敏感性对照 | 描述观察购买构成是否集中于少数商品；目录不完整的可售状态限制其组合经营解释 |
| 款式族变体覆盖 | 同一 `product_code` 组中有购买记录的不同 `article_id` 数；同时报告目录变体数 | 目录缺少库存和上架记录，变体购买覆盖不等于售罄或供给利用率 |
| 目录变体购买覆盖率 | 同一款式族中至少有一条购买记录的不同 `article_id` 数 ÷ 该款式族目录中的不同变体数 | 只衡量训练期的目录变体购买覆盖，不代表在售库存或售罄率 |
| 颜色／图案构成 | 按 `colour_group_name`、`perceived_colour_master_name`、`perceived_colour_value_name`、`graphical_appearance_name` 汇总购买件数、买家数和占比 | 颜色组、主色系、明暗和图案是不同口径；不把销售构成解释成缺货或颜色因果偏好 |
| 客户观察购买日数 | 每客户 `COUNT(DISTINCT t_dat)` | 同日买多件只算一个购买日；不是订单频次 |
| 第 N 个观察购买日后 H 日再次购买日率 | 对每个客户按不同 `t_dat` 排序。对第 N 个购买日，只纳入 `第 N 日 + H 天 <= 数据截止日` 的客户；分子为其第 N+1 个不同购买日在 `(第 N 日, 第 N 日 + H 天]` 内的客户数，分母为具备完整 H 日观察窗的第 N 次购买客户数 | 首版 H 取 30／60／90 天；先单独显示 N=1、2、3，样本允许再按具体 N 展开。4+ 只用于购买日数分布，不合并进第 N 次回购率 |
| H 日窗口未观察到再次购买比例 | 在同一第 N 次购买、完整 H 日窗口合格人群中，窗口内未观察到第 N+1 个购买日的人数 ÷ 合格人数 | 可回答“第几次后较少观察到回购”，不能命名为放弃品牌、流失客户或流失原因 |
| 相邻观察购买日间隔 | 对存在后续购买日的客户计算 `DATEDIFF(下一购买日, 当前购买日)`；报告中位数和样本数 | 间隔统计只描述已观察到再次购买的人；无下一次购买者另按完整观察窗口统计，不能遗漏后再代表全体 |
| 同款跨日再次购买客户率 | 对一个 `article_id` 或候选 `product_code`，统计在两个或以上不同购买日出现的客户 ÷ 买过该款式的客户 | 相同行的同日重复购买不算跨日复购；可区分具体变体复购与款式族复购，不代表品牌忠诚因果 |
| H 日同款族再次购买率 | 对每个客户与候选 `product_code`，从首次观察购买日开始；只纳入购买日后有完整 H 日窗口的客户－款式族组合。分子为窗口 `(首日, 首日 + H 天]` 内再次购买该款式族的组合数，分母为完整观察组合数 | H 取 30／60／90 日；可与“任意 H&M 商品再次购买日率”并列比较，款式族仍为候选定义 |
| 客户品类广度与集中度 | 每客户购买过的不同商品组数；以及其最大单一商品组购买件数 ÷ 该客户总购买件数 | 描述客户类别覆盖和主类占比，不用消费金额加权；同日多件按购买件数计 |
| 长间隔后回购 | 相邻两个不同购买日间隔达到预设 90 天后仍有下一次购买的客户数和购买间隔 | 称“长间隔后回购”，不是营销召回或沉睡客户激活 |
| 截止日近期性 | 数据截止日 2020-09-22 减去客户最后观察购买日；按 0–30、31–60、61–90、91 天以上分组 | 是历史样本中的观察近期性，不表示 2026 年或当前客户状态 |
| 客户近期性 × 购买日频次分层 | 将客户距末次观察购买日天数与观察购买日数交叉，展示客户数及对应的历史购买件数 | 作为不含金额的“近期性—频次”行为分层，不能称完整 RFM 客户价值或当前运营名单 |
| 首现月份组 H 日回购率 | 按客户首次观察购买月分组，计算首次购买日后完整 H 日窗口内有无下一不同购买日 | 与第 1 次购买日回购率为同一底层定义的月份切片；不能解释为真实拉新 cohort 或营销留存 |
| 渠道构成与跨编码切换 | 按编码统计购买件数、买家数；客户两个编码都有购买即“观察到多编码购买”。跨日切换只使用单一渠道编码的客户购买日相邻配对；同日两编码均有记录的日期单列为混合编码日 | 编码未映射前不称线上／线下；不计算到店、转化和线上向线下因果导流 |
| 客户购买件数均值 | 观察购买件数 ÷ 活跃购买客户数 | 不是客单价、每单件数或消费金额 |
| 源价格数值分布 | 展示源 `price` 的中位数、分位段及样本数，可按品类、颜色、渠道代码和月份分组 | 仅作源数值比较；禁止求和、换算货币或称折扣、售价、营收 |

年龄段建议为 16–17、18–24、25–34、35–44、45–54、55–64、65+ 和未知；只汇总展示。高空值客户属性要显示有效覆盖率。多个颜色、分类或渠道同时出现在同一客户购买日时，按类别拆分的客户数可能重叠，不应期待分项加总等于总客户数。

## 5. 商业分析视角扩展矩阵

| 分析视角 | 交叉维度 | 主要问题与展示指标 | 可支持的讨论 | 边界 |
| --- | --- | --- | --- | --- |
| 商品品类与经营层级 | 商品组、类型、服装组、`index_group`、`index`、部门、版块 × 月份／季度／渠道代码 | 购买件数、买家覆盖、购买占比、同期变化、商品构成集中度 | 哪些品类／版块构成核心，哪些类别长尾，哪些组合需要复核 | 目录无商品上架期和库存，不称售罄、周转或市场份额 |
| 商品组合集中度 | 商品组、`article_id`、候选 `product_code` 的前 10／前 20 购买件数占比 × 月份／类别／渠道编码 | 头部款式占比、头部变化、长尾分布 | 观察购买是否集中于少量款式，便于检查组合依赖 | 只衡量数据中已发生的购买，不代表完整在售商品组合或市场需求 |
| 款式族与变体 | `product_code` 候选款式族 → `article_id` 具体款式变体 × 类型／渠道／时间 | 款式族购买排名、买家数、族内变体数、各变体购买占比 | 一种款式的不同变体是否呈现不同购买表现，表现是否集中在少数变体 | 314 个款式族有多个类型、96 个有多个商品组；保留冲突，不强行归类 |
| 颜色、主色与明暗 | 颜色组、主色系、感知颜色值 × 商品组／类型／版块／年龄段／渠道代码／月份 | 颜色购买构成、买家覆盖、款式族内颜色变体构成、季节变化 | 哪些颜色构成随品类、客群或时间有不同表现 | 买不到某色与不喜欢某色无法区分；无库存和曝光 |
| 款式复购与变体覆盖 | 同款式族、同具体变体在客户不同购买日之间 × 会员状态／年龄段／渠道代码 | 具体变体跨日重复购买客户率、30／60／90 日同款族再次购买率、目录变体购买覆盖率 | 哪些款式有较多跨日重复购买，款式族内购买是否集中于少数变体 | 多件同日不算重复日期；目录没有可售状态，覆盖率不等于库存售罄 |
| 图案、服装组与文本描述 | 图案、服装组、`detail_desc` 关键词 × 类型／颜色／时间 | 图案购买构成；经核验的材质、领型、版型等文本关键词比较 | 提出商品设计属性假设，辅助商品组合讨论 | 描述文本缺失且写法不统一；机器提取结果须抽样人工核验，不能当源标准分类 |
| 客户回购阶段 | 第 1、2、3 个不同购买日，并在样本足够时按具体 N 后续展开；另以 1、2、3、4+ 做客户购买日数分布 × 年龄段／会员状态／首个渠道代码／前次品类 | 合格样本数、30／60／90 日再次购买日率、未观察到回购比例、购买间隔 | 哪个具体回购阶段的回访比例下降，哪些客户群值得进一步研究 | 左侧历史不完整；末次购买右侧观察受限；不得称真实品牌流失或原因 |
| 首现月份组与客户行为分层 | 观察期首次购买月份 × H 日回购；最近一次观察购买距截止日 × 不同购买日数 | 月份组样本数、30／60／90 日回购率、近期性—频次分布 | 对比不同观察月份客户的后续购买节奏，并定位历史上较久未购买的分层 | 首次观察不等于获客；近期性只截至 2020-09-22；不含消费金额 |
| 客户品类偏好与广度 | 客户购买过的商品组／类型／颜色数和各类购买件数占比 × 会员状态／年龄段 | 客户品类广度、主类集中度、颜色与款式多样性 | 区分购买范围较集中和跨品类较广的历史行为，研究其后续回购差异 | 同日多件按件数加权但无订单信息；高空值属性显示覆盖率 |
| 客户近期性与回流 | 最后观察购买距 2020-09-22 天数、客户历史购买日数、长间隔后再次购买 | 近期性分层、购买日数分布、90 天以上购买间隔后的回购占比 | 识别历史沉寂样本和长周期客户行为 | 只代表 2020-09-22 前；不能作为当前客户名单或实际召回效果 |
| 渠道与跨渠道 | 源编码 1／2 × 商品层级／颜色／月份／客户属性；客户日序列 | 渠道代码购买构成、客户覆盖、两代码客户重合、单码相邻日期切换 | 权威映射后比较线上／线下商品结构及跨渠道行为 | 官方渠道名称映射尚未核实；无曝光、门店、设备和订单信息 |
| 品类旅程 | 客户相邻的不同购买日期 × 前日／后日类别集合 | 观察到的类别迁移矩阵和样本数 | 查看客户在不同日期的类别偏好如何变化 | 同日商品不是订单；相邻日期类别变化不等于同篮连带或交叉销售 |
| 时间与价格代理 | 月、季度、星期 × 类别／款式／颜色／渠道代码 | 完整月趋势、星期构成、源价格分布分位数 | 观察季节性和相对源数值差异 | 仅约两年；首尾月不完整；价格没有货币和折扣定义 |

## 6. 首版交付优先级

| 优先级 | 分析内容 | 原因 |
| --- | --- | --- |
| P0 商品主线 | 商品层级、款式族与变体、颜色／主色／明暗、图案，按时间和渠道代码比较 | 字段覆盖广，直接支持用户确认的商品／品类优先方向 |
| P1 客户回购 | 第 N 个观察购买日后 30／60／90 日再次购买日率、购买间隔、近期性和长间隔后回购 | 对应客户运营问题；需明确合格观察窗口和“未观察”语义 |
| P1 渠道行为 | 源编码构成、渠道客户重合、跨编码切换；在线／线下映射核实后再命名 | 能观察渠道差异，但解释渠道之前先核实编码定义 |
| P2 探索扩展 | 跨购买日品类旅程、文本关键词、更多客户分群、图片特征 | 能增加商品和客户洞察；需要额外验证并控制范围 |

## 7. 验收口径

1. 商品主线可按商品组、类型、版块、款式族候选、具体变体、颜色和图案分组，并显示购买件数、买家数和样本数。
2. `product_code` 汇总保留与 `article_id` 的下钻，分类冲突不得静默丢弃；款式族内部各变体购买件数之和与族级购买件数可核对。
3. 第 N 个观察购买日指标对每个 N 和 H 显示合格客户数、再次购买客户数、分子、分母和数据截止日；同日多商品只计一个购买日。
4. “窗口内未观察到回购”不得改名为流失／放弃品牌；只有完整 H 日观察期的人群进入对应分母。
5. 渠道映射核实前只显示 1／2 编码；跨渠道切换使用相邻且单编码的不同购买日配对，混合编码日单独列示。
6. 类别旅程按相邻购买日分析，不提供购物篮／连带率；源价格不得显示为货币金额或营收。
7. 头部商品集中度按购买件数计算，并显示前 10／前 20 商品范围；首现月份组只称观察期首次购买月份，不能改称新客留存。
