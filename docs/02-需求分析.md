## 1. 文档范围

本文件说明系统为谁服务、解决哪些业务问题、包含哪些功能、指标如何定义，以及如何判断需求得到满足。具体来源与字段见 [数据来源与数据字典](03-数据来源与数据字典.md)，模型与存储设计由各设计文档负责，工具与版本见 [技术栈与版本](01-技术栈与版本.md)。

## 2. 已知约束与依据

- 面向真实行业设计并实现数据仓库，满足业务决策分析需要；行业与具体场景待确定。
- 完成需求分析、概念设计、逻辑设计、物理设计、实现与可视化分析。
- 数据模型必须体现分层思想；课程举例为 ODS-DWD-DWS-ADS，具体方案待逻辑设计阶段确定。
- 采用真实、可靠且来源可追溯的数据，不人为构造虚假业务数据。
- 支持 macOS 与 Windows 使用；具体系统版本、处理器架构和资源要求待后续验证。
- 工具选型以技术栈文档中的已确认项为准；工具采用不代表其具体功能已经列入需求。

课程依据：[期末大作业要求](课程原始文档/期末大作业要求.pdf)。报告、答辩及材料提交要求统一见 [答辩与交付](11-答辩与交付.md)。
