## 演示与录屏准备

课程要求提前录制关键功能。以下为待彩排的操作路径，核对值来自已记录的实现阶段检查。

| 演示环节 | 操作与核对点 |
| --- | --- |
| 数据接入 | 打开 Streamlit 原始文件接入页，展示三份 CSV 的完整性核验。结合[装载记录](07-数据处理设计.md#6-实机装载记录)说明 Doris 的 25 个交易月分区、31,788,324 条购买记录及客户、商品和日期关联未匹配均为 0。 |
| 商品组合 | 在 Streamlit 选择全期，展示候选款式族前 10／20 名占比分别为 3.29%／5.23%，再下钻 `706016`，核对 183,921 件与 27 个有购买记录的变体。黑色、深蓝和浅蓝合计 149,619 件，占该候选款式族购买件数的 81.35%。 |
| 看板筛选 | 在 Metabase 商品概况选择 2020 年 7 月、渠道编码 1，核对 535,082 件及 145,757 名购买客户。 |
| 客户回购 | 在 Streamlit 查看全期首次观察购买日后的 30 日回购结果。说明仅纳入完整观察窗口，核对 376,347 名再次购买客户、1,338,029 名合格客户与 28.13% 的再次购买日率。 |

录制前先按[运行说明](10-部署与运行.md)检查服务和看板入口，再按录屏顺序复核筛选及结果。成员分工确定后安排出场和交接顺序，全体成员参加答辩，并按教师公布的时长彩排。

款式案例由原始商品和交易文件按 `article_id` 关联复算，并与 Doris 聚合交叉核对。当前全期结果可用以下查询复核。

```sql
SELECT colour_group_name,
       COUNT(*) AS purchase_items,
       COUNT(DISTINCT article_id) AS purchased_variants
FROM hm_retail_dw.v_purchase_detail
WHERE product_code = 706016
GROUP BY colour_group_name
ORDER BY purchase_items DESC;
```
