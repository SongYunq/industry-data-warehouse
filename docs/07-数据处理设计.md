## 1. 数据源命令

当前下载、校验和文件结构盘点由 `src/inside_airbnb/` 提供，默认读取 [下载校验清单](附件-数据下载校验清单.csv)。Pixi 默认数据任务使用 Inside Airbnb 工具：

| 命令 | 行为 | 验证状态 |
| --- | --- | --- |
| `pixi run data-fetch` | 按清单下载全部缺失或校验不匹配的文件；SHA-256 和字节数均匹配的本地文件直接复用 | 已对本地 84 个文件验证复用和完整性核验路径 |
| `pixi run data-fetch-all` | 同上，保留明确表示全量数据范围的任务别名 | 已配置；本轮没有重新联网下载 |
| `pixi run data-check` | 对清单所选文件核对字节数和 SHA-256；可用城市键和快照日期筛选 | 全部 84 个文件通过 |
| `pixi run data-inspect` | 顺序读取 CSV、GZIP CSV 和 GeoJSON，统计行数、列数、日期范围、可订值和几何类型；可用 `--output` 另存 CSV 概况 | 已检查全部 84 个文件，列数不匹配记录为 0 |
| `pixi run dashboard` | 启动 Streamlit 原始文件盘点页 | 页面代码已实现；浏览器验收未做 |

筛选参数示例：`pixi run data-inspect -- --city hong_kong --snapshot 2026-09-20`。城市值为 `hong_kong`、`tokyo`、`singapore`；未指定筛选时处理清单中的全部文件。

## 2. 完整性和失败处理

- 清单记录城市、快照日期、下载地址、项目内落盘路径、字节数和 SHA-256。程序校验路径位于 `data/raw/inside_airbnb/` 下，下载来源限于 Inside Airbnb HTTPS 域名。
- 下载使用临时 `.part` 文件；下载完成后核对字节数和 SHA-256，匹配后才替换目标文件。失败时清理临时分片并重试，最多 3 次；旧目标文件在新下载校验通过前保留。
- 文件完整性核验会读取文件内容计算摘要；结构盘点会完整读取 CSV 数据流，并在结束时检查 GZIP 流是否正常读完。
- 当前清单固定覆盖 12 个季度快照和 84 个文件。未来若扩展城市或快照，应先更新并复核清单。
