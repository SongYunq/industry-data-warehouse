# 项目文档索引

最后更新：2026-11-12（Asia/Shanghai）

## 当前范围

核心数据源为 Inside Airbnb，首批范围是香港、东京、新加坡近一年可取得的季度快照：每城 4 期，共 12 个快照、84 个原始文件，合计 1,174,273,252 字节。数据下载、文件级完整性核验和初步结构盘点已完成，文件保存在 `data/raw/inside_airbnb/`。

技术路线为 Pixi + Python、Apache Doris、Streamlit、Metabase、PostgreSQL 和 Docker Compose。项目当前停在 W04 前；尚未完成业务需求与指标口径、数据建模、Doris 数据接入或业务看板。文档建立不代表阶段完成，实际状态统一见 [工作内容与进度](00-工作内容与进度.md)。

## 代码与数据入口

- `src/inside_airbnb/`：按清单获取数据、校验字节数和 SHA-256，并盘点 CSV、压缩 CSV 与 GeoJSON 结构。
- `apps/streamlit/app.py`：只读检查三城快照文件、记录数和完整性；不计算业务指标。
- `src/warehouse/`：Docker Compose、Doris 和 Metabase 的共享服务管理代码。
- `data/raw/inside_airbnb/`：本地原始数据，由 Git 忽略。
