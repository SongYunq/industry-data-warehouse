# 项目文档索引

最后更新：2026-11-13（Asia/Shanghai）

## 当前范围

当前数据源为 Kaggle H&M Personalized Fashion Recommendations 竞赛数据。三张核心 CSV 已完成下载、SHA-256、结构和首轮数据质量盘点。W04 扩展版方案纳入商品款式族候选、变体、颜色、明暗、图案、商品组合集中度、客户第 N 个购买日回购、首现月份组和渠道切换；用户确认商品／品类优先，客户回购与渠道构成为辅。W05 概念和 W06 逻辑模型已同步扩展，并已补齐概念关系、事实维度、字段血缘、物理分区和数据处理流程图；Doris 实机已创建 4 张表、装载 25 个自然月分区并验证单月重载。Streamlit 已连接分析库，Metabase 已使用聚合视图只读账号发布 H&M 看板。

技术路线保持 Pixi + Python、Apache Doris、Streamlit、Metabase、PostgreSQL 和 Docker Compose。Airbnb 香港试点文件、代码、SQL、文档和证据已归档；据历史试点记录，Doris 的 `hk_airbnb_pilot` 曾有 10 张表并部分装载首期数据。本轮确认 Doris FE/BE 存活、5 个数据卷仍存在，历史库仍有 10 张表。详细状态见 [工作内容与进度](00-工作内容与进度.md)。

## 代码与数据入口

- `src/hm_recommendations/`：H&M 文件获取、核验、结构盘点、入仓、分析视图安装与 Metabase 发布。
- `apps/streamlit/app.py`：商品、客户和渠道分析看板，含原始文件接入页。
- `src/warehouse/`：Doris、Metabase 与 PostgreSQL 共享服务管理代码。
- [Doris 建表脚本](../sql/hm_recommendations/001_schema.sql)、[分析视图](../sql/hm_recommendations/002_analytics.sql)、[Metabase 只读授权](../sql/hm_recommendations/003_metabase_reader_grants.sql)。
- `data/raw/hm_recommendations/`：H&M 原始文件，已下载并由 Git 忽略。
- `data/archive/inside_airbnb/`：保留的 Airbnb 历史原始文件，由 Git 忽略。
- `archive/inside_airbnb/` 与 [Airbnb 归档资料](archive/inside_airbnb/README.md)：旧数据源专属代码、SQL、设计和盘点证据。

5. 修订已确认内容时更新所属文档，并核对相关引用与实现。
