- 文档职责：维护分析主题、Streamlit 与 Metabase 的页面职责、图表和交互

## 1. 页面目标

看板以商品表现为主，客户复购和线上线下对比为辅。数据覆盖 2018-09-20 至 2020-09-22，用于课程教育和研究。

## 2. 页面分工

Streamlit 是本阶段的分析界面，直接查询 Doris。Metabase 自助分析的正式接入列入下一阶段。

### Streamlit 布局

左栏直接切换页面。日期、渠道和商品类型按当前页面需要显示，点击「应用筛选」后生效。共用的筛选值切页后保留。款式选择、颜色与图案切换、描述词搜索放在各自页面中。窄屏通过左上角展开侧栏。

## 3. 页面与分析图表

| 页面 | 展示内容 |
| --- | --- |
| 购买概览 | 购买件数、购买客户数、买过的款式和商品数、每月趋势、购买最多的商品组 |
| 商品分类 | 按商品组、商品类型、服装组或商品版块查看购买件数、买家数和占比 |
| 款式排行 | 按款式编号或商品编号看购买排行和前 10／20 名占比；选款式后查看商品与颜色明细 |
| 颜色与图案 | 分别查看颜色、图案的购买件数和占比，可用商品类型筛选比较同类商品 |
| 商品描述词 | 按命中购买件数排序，可按商品类型筛选或查找描述词 |
| 客户复购 | 第 1、2、3 次购买后截至数据结束的复购，以及 30／60／90 天内复购；两表均列出统计人数、复购人数和比例 |
| 线上与线下 | 两个渠道的每月购买件数、客户在哪些渠道买过，以及购买最多的商品组 |
| 文件核验 | 三张原始 CSV 的文件状态和字节数，按需执行 SHA-256 核验 |

跨日品类旅程已从业务范围移除。跨渠道相邻日切换、首购月份分组、近期购买与频次、客户品类广度、客户属性分组、同款复购及明暗等细分分析撤出当前看板。历史查询及扩展指标见 [需求分析](02-需求分析.md)。

### 客户复购

日期筛选选的是对应第几次购买的日期。一位客户同一天的记录合并为一次购买，序号根据全量购买日期确定。后续购买统一查到 2020-09-22。固定天数的表中列出最晚计入的购买日，30 天为 2020-08-23，60 天为 2020-07-24，90 天为 2020-06-24，包含当天。没有符合条件的客户时，人数为 0，比例留空。公式见 [指标口径](02-需求分析.md#4-指标口径)。

### 商品描述词条

在左栏直接选「商品描述词」。图表显示有购买的前 15 条，表格保留完整排行。搜索保留当前筛选下的名次。目录中的商品数按商品类型筛选统计，含零购买件数的商品。见 [W04 词条排行](02-需求分析.md#9-商品描述词条购买件数排行)。

## 4. 全局筛选与图表语义

- 商品页和购买概览支持日期、渠道和商品类型。线上与线下页保留两种渠道，支持按日期、商品类型比较。
- 复购页只筛选起始购买日。文件核验页独立读取本地原始文件状态。
- 趋势图标出部分月份。渠道标签采用线下（1）与线上（2）。同一客户可购买不同分类，分项买家数可能重叠。
- 款式编号对应 `product_code`，用于将目录商品归组；商品编号对应 `article_id`。一个款式编号下有多种商品分类时，明细页提示实际分类数。

## 5. 统一解释边界

商品指标、复购期限及渠道口径见 [需求分析](02-需求分析.md)，源字段与款式编号结构见 [数据字典](03-数据来源与数据字典.md)。看板使用购买件数与汇总客户数，对个人客户不展示明细。

## 6. 实现和验收顺序

1. 核对购买概览、分类、款式排名和具体商品合计。
2. 核对复购人数、比例与各期限截止日。
3. 核对线上和线下件数、客户重合、描述词搜索与空结果。
4. 系统验收见 [W11 验收计划](09-测试与验收.md)。

## 8. 中英双语展示

Streamlit 的筛选项、图表和表格采用“英文（中文）”格式。逐项核对商品和客户源文件的 13 个字段，共在[分类词表](../src/hm_recommendations/label_translations.csv)补充 602 个分类值。另有 5 个纯品牌或系列名称值保留原文。

Streamlit 的款式明细保留完整商品名，并为名称中可识别的服装类型、版型、材质等通用词补充中文。例如 `Adele shape Swimsuit（泳衣）`。在 45,875 个不同商品名中，有 31,205 个匹配到通用词；其余名称仍可通过同表的双语商品类型和颜色理解。商品编号、渠道编码和专名沿用原值。筛选、分组和购买件数均以原始值计算。

本机验证 Streamlit 商品概况已显示双语标签。Metabase 原型的双语检查见下节。
