# 分析与可视化设计

- 状态：商品、款式、颜色、客户回购和渠道行为分析方案已扩展；W10 页面开发与验收未开始
- 最后更新：2026-11-12（Asia/Shanghai）
- 文档职责：维护分析主题、Streamlit 与 Metabase 的页面职责、图表和交互

## 1. 页面目标

看板顺序遵循用户确认的主题优先级：先看商品／品类，再看客户购买日回购阶段和渠道行为。商品分析下钻到 `product_code` 款式族候选、`article_id` 具体变体、颜色、明暗和图案；客户页面围绕第 N 个不同购买日后有无后续观察购买；渠道页面先用编码 1、2，映射核实后才改用线上／线下标签。

本项目是课程用途的历史分析工具。竞赛数据只用于非商业研究和教育。

## 2. 页面分工

| 展示端 | 首版职责 | 交互 |

## 3. 页面与分析图表

### 经营概览

- 指标卡：观察购买件数、活跃购买客户、观察到购买的款式族／变体数、第 1 个不同购买日后 30 日再次购买日率（仅完整观察窗）和多渠道编码客户比例；回购率卡片同时显示合格样本数。
- 时间图：按完整月查看购买件数、活跃客户和商品组合变化。首尾部分月份独立标示，不作为完整月环比。
- 品类组合图：商品组、商品类型、版块的购买构成和买家覆盖，支持按颜色、图案或渠道代码筛选。
- 指标卡显示合格样本数、日期截止日和口径入口；不使用订单数、营收、毛利、售罄率或转化率。

### 商品组合、款式与颜色

- **商品层级图**：按商品组、类型、服装组、`index_group`、`index`、部门和版块查看购买件数、买家数、占比和月份变化。
- **商品组合集中度**：按购买件数显示前 10／前 20 个 `article_id` 或候选 `product_code` 的占比，并查看各月、品类与渠道编码下的变化。该数值描述观察购买集中程度，不代表完整在售范围的市场份额。
- **款式族到变体图**：先按候选 `product_code` 排名，再下钻至 `article_id`；对同一款式族比较各变体的购买件数、买家覆盖和变体占比。图例明确“款式族候选”，分类冲突显示提示。
- **颜色矩阵**：颜色组 × 商品类型／版块热力图；支持切换主色系和感知明暗值，按月份或渠道编码分面比较。
- **图案比较**：图案 × 商品组／类型条形图或热力图；低频类别可筛选，不静默并入其他类。
- **款式族内部颜色构成**：在目录中确实有多颜色变体的款式族里，比较各变体观察购买件数占比。它描述购买构成，不代表颜色供应充分或消费者因果偏好。
- **款式复购**：比较同一 `article_id` 或候选 `product_code` 是否在客户不同购买日再次出现；同日同款多行不计跨日复购。
- **变体覆盖**：展示有购买记录的目录变体数 ÷ 款式族目录变体数，标题写“训练期目录变体购买覆盖”，不称库存售罄或需求满足。
- 目录有 995 个商品款式未在训练购买记录中出现，只显示“训练期无购买记录”，不标为滞销或缺货。

### 客户购买阶段与回购

- **购买日数分布**：客户在整个观察期内出现 1、2、3、4+ 个不同购买日的客户数和占比；注明观察期长短影响累计次数。
- **第 N 次购买日后回购图**：N=1、2、3 分开展示 30／60／90 日再次购买日率、窗口内未观察到回购比例、合格人数和实际回购人数；样本允许时再按具体 N 向后扩展。
- **回购间隔分布**：展示已观察到后续购买客户的间隔中位数和分位数，同时单独显示完整窗口内没有后续购买日的人数。间隔统计不能单独代表所有客户。
- **近期性和长间隔回购**：按距数据截止日 2020-09-22 的最近购买天数分组；展示 90 天以上间隔后再次购买的历史记录数。标题说明这是训练历史，不表示当前客户状态或营销召回效果。
- **客户分群**：按年龄段、会员状态、资讯频率和可用的源标记汇总回购指标，空值单独列出并显示属性覆盖率。
- **客户品类偏好**：显示每客户购买过的商品组／类型／颜色广度及主类购买件数占比，比较不同客户群的购买多样性和回购表现。
- **同款回购**：按不同日期计算客户重复购买同一 `article_id` 或款式族候选的比例，区分变体重复与款式族重复。
- **款式族期限回购**：对首次观察购买的客户－`product_code` 组合，比较 30／60／90 日内再次购买同款式族与再次购买任意商品的比例；只使用有完整窗口的组合。
- **首现月份组回购**：按客户首次观察购买月份分组，显示其第一个不同购买日后 30／60／90 日的再次购买日率和合格样本数。标为“观察期首现月份组”，不称真实获客月份或新客留存。
- **近期性—购买频次分层**：以距历史数据截止日的天数交叉不同购买日数，呈现汇总客户数，辅助理解历史上的低频与较久未出现记录人群；不生成当前客户名单，也不含消费金额。
- **品类旅程**：比较客户相邻不同购买日中的商品类别集合变化；多个类别在同日出现只形成日期类别集合，不解释成一个购物篮。
- 客户购买日顺序按 `customer_id + DISTINCT t_dat` 生成。数据截止前不足完整 H 日的人不进入该 H 日率的分母。

### 渠道与购买旅程

- **渠道代码对比**：编码 1／2 的购买件数、买家数、商品组、款式、颜色、图案和月份构成。在官方含义核实前始终显示编码。
- **客户跨码行为**：显示只用单一编码、多编码都有购买的客户数及占比。相邻购买日切换率只取两日各自只有一个渠道编码的客户；同日多编码的客户日单独显示。
- **线上／线下视图**：取得权威代码映射后，可将渠道页标题与图例映射到线上／线下，再比较商品结构和客户回购。不能据此推断渠道转化率、增量或线下门店表现。
- **跨购买日品类旅程**：以客户前后相邻的不同购买日为序，比较两日商品分类集合的变化。它不是同订单连带、购物篮或交叉销售归因。

### 源价格与文本扩展

- 可选展示源 `price` 的分布、分位段和不同商品／颜色／渠道代码的数值差异；不做货币换算和求和。
- 后续可从 `detail_desc` 试验提取材质、版型或场景关键词；仅在词典和抽样人工核验后展示。竞赛商品图片未纳入当前数据，图片分析属后续扩展。

## 4. 全局筛选与图表语义

- 日期筛选限定 2018-09-20 至 2020-09-22；月度图区分完整月和部分月。
- 商品筛选包括商品组、类型、服装组、部门、版块、款式族候选、变体、颜色组、主色系、明暗值和图案。分类值冲突可回到 `article_id` 明细汇总核对。
- 客户筛选包括年龄段和会员等静态快照属性，未知单独呈现。高空值字段显示覆盖率，不默认把空值转成否。
- 渠道名称尚未核实，代码 1、2 分别作为值；类别迁移和渠道切换均标出分母定义。
- 每个图表显示样本数、日期范围和度量单位。多标签分群的客户数可能交叉重叠，不要求各组相加等于总体。
- 展示默认保持汇总粒度，不开放客户伪名键、邮编哈希或个体目标名单。

## 5. 统一解释边界

商品指标、回购窗口、未观察到回购、渠道切换、源价格和部分月的精确定义见 [需求分析](02-需求分析.md)。事实字段与 `product_code` 结构观察见 [数据来源与数据字典](03-数据来源与数据字典.md)，客户购买日派生关系见 [逻辑设计](05-逻辑设计.md)。

没有库存、曝光、订单、退货、成本和活动数据时，图表不显示售罄、订单、购物篮、收入、利润或活动增量。样本未继续购买只能表述为“在完整观察窗口内未观察到下一购买日”，不得写成客户放弃 H&M。

## 6. 实现和验收顺序

1. Doris 建表、装载后，先做经营概览和商品层级／款式／颜色查询。
2. 校验 `product_code` 款式族汇总与 `article_id` 下钻、分类冲突提示、颜色变体合计和商品前 10／20 份额。
3. 实现客户购买日序列与第 N 次回购窗口，按独立查询核对分子、分母和样本数；增加首现月份组回购及近期性—频次分层。
4. 验证渠道代码名称；若仍无权威映射，保留编码视图，再完成跨编码客户和购买日切换比较。
5. 验收日期、空值、窄屏、无样本筛选和客户隐私汇总显示。
