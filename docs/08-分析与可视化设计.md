### 2.1 初次构建范围与落实情况

初次构建只要求环境打通并能够导入原始数据。正式页面、图表、指标和业务看板不作为初次构建完成条件。

首版技术接入页面落实情况：
- **Streamlit**（`apps/streamlit/app.py`）：通过 `pixi run dashboard` 在本机 `http://127.0.0.1:8501` 启动，展示 Doris FE／BE 集群存活状态、已导入批次及元数据汇总、前 20 条原始抽样记录和最近一次核验清单（`latest_check.json`）；不暴露密码，不提供文件上传或导入按钮。
- **Metabase**（`http://127.0.0.1:3000`）：通过容器加载 `doris.metabase-driver-v1.0.0.jar`，已连接容器内部网络 `doris-fe:9030`（库 `raw_lade`），并将自身应用配置保存在独立 PostgreSQL `18.6`（`metabase_app`）；已在 Mac 验证驱动注册、21 个字段自动发现及原生 SQL 查询。具体启动与访问步骤见 [部署与运行](10-部署与运行.md)，验证记录见 [测试与验收](09-测试与验收.md) 用例 `I03`、`I09`、`I10`。
