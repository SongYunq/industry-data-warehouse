# 工作内容与进度

最后更新：2026-11-13（Asia/Shanghai）

## 当前概况

用户已将当前数据源由 Inside Airbnb 改为 Kaggle H&M Personalized Fashion Recommendations，技术路线不变。三份核心 CSV 已完成下载、字节数、SHA-256、结构和首轮质量盘点：交易 31,788,324 行、客户 1,371,980 行、商品 105,542 行；交易客户和商品关联未匹配行均为 0。交易覆盖 2018-09-20 至 2020-09-22 的 734 个连续自然日。

此前 84 个 Airbnb 原始文件（1,174,273,252 字节）已移动至 `data/archive/inside_airbnb/`；迁移后逐文件 SHA-256 与归档清单一致。旧来源下载器、香港试点看板、SQL、阶段文档和证据附件已归档。根据香港试点历史记录，`hk_airbnb_pilot` 曾建 10 张 Doris 表并部分装载首期数据；本轮实机复核历史库仍有 10 张表，5 个共享数据卷仍存在。

Doris 的 `hm_retail_dw` 已完成全量装载。4 张表、25 个交易月分区通过检查，31,788,324 条购买记录与源文件一致；客户、商品、日期外键未匹配均为 0，单月重载通过。Streamlit 已接入仓库，按商品／品类、客户回购、渠道与品类旅程展示。Metabase 已登记 H&M 只读数据源并发布 4 个标签页、12 张卡片的看板。原始数据保存在 Git 忽略目录。
