## 当前概况

- 当前阶段：核心数据源已选定，初次构建技术方案的文档准备已完成；业务需求与数据资料整理继续进行。
- 已完成：阅读课程要求，建立项目文档体系与维护约定，确定国内快递末端揽派场景及 `Cainiao-AI/LaDe` 核心数据源。选型依据见 [数据源选取](12-数据源选取.md)。
- 已确认的业务方向：围绕揽收、派件与快递员轨迹数据，分析单量分布、履约时效、片区负荷与快递员作业效率、空间与轨迹特征；需求边界见 [需求分析](02-需求分析.md)。
- 已确认的技术方向：Python 3.14 系列，本机开发使用 Pixi，交付携带必要环境定义与锁文件；Apache Doris 承担业务分析数仓，Streamlit 与 Metabase 同时展示分析，Metabase 配置使用独立 PostgreSQL；数据库等服务采用 Docker。
- 已确认的初次构建目标：环境打通并能够导入一个城市的一份完整原始文件；首版优先必要组件，不默认增加额外平台。
- 技术完善方式：四轮十五项约束均已确认，当前没有新的用户偏好待问；初次构建的版本基线、目录、配置、命令任务、原始接入和验收计划已写入所属文档。
- 已确认的运行约束：首批 Apple 芯片 Mac 与 Intel／AMD Windows，推荐 16 GB 内存，默认仅本机访问；自动获取原始文件并支持已有文件；默认数据目录与持久化卷可配置；未来先 Mac 再 Windows 验收。
- 当前工作边界：只完善文档，不创建代码或实际环境配置，不安装依赖、下载业务数据、启动服务或构建；实施由用户后续另行安排。
- 已整理：数据源覆盖范围、选型文档记载的规模、已列明字段及数据局限，见 [数据来源与数据字典](03-数据来源与数据字典.md)；尚未下载数据或完成样本探查。
- 尚未开展：完整业务模型设计、开发环境搭建、数据接入与处理实现、功能开发、联调和运行验证；首次原始接入的有限设计仅作为文档方案存在。
- 正式题目、使用者职责、指标计算口径、配套融合数据源、成员分工及里程碑日期尚未确认；工具已有文档版本基线，实际依赖、镜像及驱动兼容性尚未验证。
- 数据源为历史归档数据；项目更新频率与运行方式尚未定版，不将历史日期回放说明视为已实施的每日增量加载。

本文件记录实际工作进度，不把文档骨架视为对应业务工作已完成，不估算无依据的完成百分比。
