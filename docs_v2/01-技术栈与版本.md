# V2 技术栈与版本

最后更新：2026-11-12（Asia/Shanghai）

## 1. 已确认结论

用户明确要求技术路线保持不变。本项目沿用原 V1 的职责分工：Pixi 管理 Python 环境和任务；Python 承担文件获取、读取与处理；Apache Doris 作为分析数仓；Streamlit 用于定制交互界面；Metabase 用于自助查询和看板；PostgreSQL 保存 Metabase 应用配置；Docker Compose 管理数据库与展示服务。

V1 版本基线和服务编排入口见 [原技术栈文档](../docs/01-技术栈与版本.md)、pixi.toml、pixi.lock、deploy/compose.yaml。当前版数据源工具位于 `src/inside_airbnb/`，文件盘点页位于 `apps/streamlit_v2/`。沿用既有环境中的 httpx 发起下载，使用 Python 标准库读取压缩 CSV、CSV 和 GeoJSON；本次未增加依赖。

## 2. V2 适用性

Inside Airbnb 原始文件为 GZIP 压缩 CSV、普通 CSV 和 GeoJSON。现有 Python 标准库提供 gzip、csv、json 文件读取能力；本次下载和文件完整性检查使用标准库，没有新增依赖。

| 项目 | 当前结论 | 待落实 |
| --- | --- | --- |
| Doris | 沿用 V1 版本基线 | V2 数据库、表、分区、导入和文件规模兼容性 |
| Python 环境 | 沿用 Pixi 与 V1 锁文件基线 | Windows 环境恢复、V2 任务依赖和实际兼容性 |
| 文件接入 | V2 命令已按文件清单下载、校验 SHA-256 并盘点结构 | 下载恢复策略的后续维护、Doris 加载与失败处理方案 |

## 3. 版本与验证状态

版本清单不在此重复，以 V1 原技术栈、依赖锁文件和 Compose 配置作为现有基线。V2 开始构建时检查原版本是否仍适用；若无需变更，记录复核证据；若有变更，再同步版本清单。

目前仅确认数据源切换不改变技术路线。数据命令已在现有 Pixi 环境运行并完成文件核验；尚未执行 V2 专属依赖解析、Docker 服务启动、Doris 连接、原始文件导入或 Metabase 查询。Streamlit 页面代码已切到 V2 文件盘点，但尚未通过浏览器验收。Mac 上 V1 的既有通过记录不等于 V2 完整环境验证通过，Windows 仍需单独验收。
