技术路线沿用 V1。当前 `.env.example` 已包含 V2 文件清单入口和下载超时；数据文件按清单落到 `data_v2/raw/inside_airbnb/`。服务没有在本轮启动，Doris 数据库和表尚未设计，V1 的导入与自检命令不能视为 V2 可用。

已实现的数据命令见 [07-数据处理设计](07-数据处理设计.md)。`pixi run data-fetch`、`pixi run data-check`、`pixi run data-inspect` 和 `pixi run dashboard` 指向 V2；`services-up`、`services-down`、`services-status` 仍使用既有容器编排入口。服务实际启动、停止、网络连接及展示页浏览器验收均待执行。

完成前置事项后在本文件记录实际设计与验证，不用骨架替代阶段结论。当前整体进度见 [00-工作内容与进度](00-工作内容与进度.md)；职责索引见 [README](README.md)。
