# V2 项目文档索引

最后更新：2026-11-12（Asia/Shanghai）

## 当前范围

新版核心数据源已确定为 Inside Airbnb，首批下载范围为香港、东京、新加坡。数据获取按官网当前可用的近一年季度归档执行；每城取得 2025 年 12 月、2026 年 3 月、6 月、9 月的 4 期快照，共 84 个原始文件。数据下载和初步结构核对归入 W03。

技术路线沿用 V1 已确定的 Pixi + Python、Apache Doris、Streamlit、Metabase、PostgreSQL 与 Docker Compose。V2 已新增 Inside Airbnb 文件下载、完整性核验和结构盘点命令，以及一个只读文件盘点页；服务编排未在本次启动。V2 未做 Doris 入库，版本与完整环境兼容性仍待验证。W04 需求与指标口径明确保持未开始。

## 当前版代码入口

- `src/inside_airbnb/`：按下载清单获取文件、核对文件大小和 SHA-256、读取 CSV/GZIP CSV/GeoJSON 结构。
- `apps/streamlit_v2/app.py`：展示城市快照文件和记录数；不计算业务指标。
- Pixi 默认的 `data-fetch`、`data-check`、`data-inspect`、`dashboard` 任务指向 V2。
- V1 代码仍保留在原目录，旧 `docs/` 作为只读存档。
