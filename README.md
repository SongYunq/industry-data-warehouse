# Industry Data Warehouse

面向真实行业的数据仓库系统，围绕业务决策分析需求，完成从需求分析、数仓设计到数据处理和可视化分析的完整实践。

## 项目目标

- 选择一个实际行业及具体业务场景，明确需要解决的分析问题。
- 使用真实、可靠且来源可追溯的数据，不人为构造虚假业务数据。
- 完成数据仓库的概念设计、逻辑设计和物理设计，可参考 Kimball 维度建模方法。
- 根据业务需求选择离线或实时处理方式，完成数据仓库的实现。
- 通过指标查询和可视化分析展示结果，为业务决策提供支持。

项目处于前期准备阶段，已建立分阶段文档，尚未开始功能开发或部署验证。

## 初步实施路径

1. 确定行业场景、业务问题与数据来源。
2. 梳理业务过程、分析粒度、维度和指标口径。
3. 完成数据模型、分层方案及物理存储设计。
4. 实现数据采集、清洗、转换、加载与质量检查。
5. 完成分析查询及可视化展示，并验证结果。
