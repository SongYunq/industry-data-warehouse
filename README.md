# Industry Data Warehouse

最后更新：2026-11-09

面向国内快递末端揽派场景的数据仓库系统，以 `Cainiao-AI/LaDe` 为核心数据源，围绕履约与运力分析需求，完成从需求分析、数仓设计到数据处理和可视化分析的完整实践。

## 项目目标

- 围绕快递末端揽收、派件与快递员轨迹，梳理单量分布、履约时效、片区负荷与作业效率等分析问题。
- 使用真实、可靠且来源可追溯的数据，不人为构造虚假业务数据。
- 完成数据仓库的概念设计、逻辑设计和物理设计，可参考 Kimball 维度建模方法。
- 根据业务需求选择离线或实时处理方式，完成数据仓库的实现。
- 通过指标查询和可视化分析展示结果，为业务决策提供支持。

## 当前状态

项目已确定核心数据源，正在整理业务需求与数据资料，尚未下载核验数据或开始功能开发、部署验证。

- 已确定：国内快递末端揽派行业场景，采用 LaDe 揽收、派件与轨迹数据；使用 Pixi 管理 Python 环境与依赖，Apache Doris 作为业务分析数仓，Streamlit 和 Metabase 同时承担分析展示。
- 尚未确认：正式题目、具体指标口径、配套融合数据源、工具版本以及其余组件。
- 文档骨架已建立，不代表对应需求、设计或实现工作已完成。

## 初步实施路径

1. 在已选末端揽派场景与 LaDe 核心源基础上，核验数据并细化业务问题。
2. 梳理业务过程、分析粒度、维度和指标口径。
3. 完成数据模型、分层方案及物理存储设计。
4. 实现数据采集、清洗、转换、加载与质量检查。
5. 完成分析查询及可视化展示，并验证结果。
