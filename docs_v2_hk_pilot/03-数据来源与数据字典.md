# 香港数据来源与字典

- 状态：文件已取得；先锋字段映射已确定
- 最后更新：2026-11-12（Asia/Shanghai）

## 来源与范围

来源为 [Inside Airbnb Get the Data](https://insideairbnb.com/get-the-data/)，数据依据其公开数据政策提供。香港数据按季度归档，本先锋使用以下四个已下载快照：

| 快照日期 | 详细房源记录 | `price` 非空 | 房源评分均值 |
| --- | ---: | ---: | ---: |
| 2025-12-27 | 6,630 | 0 | 4.529 |
| 2026-03-29 | 2,115 | 0 | 4.631 |
| 2026-06-27 | 6,734 | 6,046 | 4.522 |
| 2026-09-20 | 6,614 | 5,603 | 4.512 |

最新版还包含 2,414,110 条未来日历记录、122,715 条详细评论记录及 18 个街区多边形。当前模型会读取日历的必要字段并汇总房态，也会从最新一期累积评论文件按月份汇总评论数；不保存评论文本或评论者字段。

## 使用字段映射

| 源字段 | 目标字段 | 清洗／用途 |
| --- | --- | --- |
| `id` | `listing_id` | 转为 BIGINT；事实键的一部分 |
| `host_id` | `host_id` | 可空 BIGINT；仅作内部字段，不在看板展示 |
| `host_is_superhost`、`host_identity_verified` | `dim_host_snapshot` | 保留为每个房东×快照的公开标记 |
| `host_since`、`host_listings_count`、`host_total_listings_count`、`calculated_host_listings_count*` | `dim_host_snapshot` | 房东公开加入日期与房源数属性；按快照保存 |
| `host_response_rate`、`host_acceptance_rate` | `dim_host_snapshot` | 去除百分号后存数值；来源为空时保留 NULL |
| `neighbourhood_cleansed`，回退 `neighbourhood` | `neighbourhood` | 首选标准化字段并去除空白 |
| `property_type`、`room_type` | 同名 | 原始分类值 |
| `accommodates`、`bedrooms`、`beds`、`bathrooms` | 同名 | 转数字；无法解析则空值 |
| `price` | `price` | 去除货币符号和千位分隔符后转数值；不填补空值 |
| `minimum_nights`、`maximum_nights` | 同名 | 转整数 |
| `availability_30/60/90/365` | 同名 | 转整数，语义为未来可订天数 |
| `number_of_reviews`、`number_of_reviews_ltm` | 同名 | 转整数；评论汇总不是订单事实 |
| `review_scores_rating` | 同名 | 转数值，空值保留 |
| `latitude`、`longitude` | 同名 | 保留到仓库供聚合地图使用，不显示单房源坐标 |
| GeoJSON `properties.neighbourhood`、`geometry` | `dim_neighbourhood` 名称与几何 | 作为街区图形边界 |
| 日历 `listing_id`、`date`、`available` | `fact_calendar_availability_day` | 关联同快照房源分类，再按快照、日历日、街区、房型、房屋类型计数 |
| 最新评论文件 `listing_id`、`date` | `fact_review_monthly` | 按评论日期月份统计评论数和有评论房源数；不读评论内容 |

## 质量发现

- 四个快照内 `listing_id` 均唯一；最新 GeoJSON 有 18 个街区要素。房型共有 4 类，四期 `property_type` 并集 73 类。
- 四期日历源文件共 8,072,340 行，本地流式汇总为 344,830 行；最新评论文件 122,715 行汇总为 188 个月份。
- 2026-03 房源记录量仅 2,115，前后期为 6,630 与 6,734。原因待核实，不解释成真实供给骤降与恢复。
- 前两期 `price` 全空，后两期才有值；因此挂牌价的跨期趋势只展示后两期，不补齐早期。
- `price_quote_*` 只出现在后三期，缺少稳定的跨期覆盖和已核实定义，先锋模型暂不使用。
- 评论文本、评论者姓名和标识不进入仓库，减少无关个人信息的保存。

官方 [数据假设说明](https://beta.insideairbnb.com/data-assumptions/) 指出房态不可用可能由预订或房东封锁造成；挂牌位置会被模糊处理。当前旧版官方 [字段字典](https://docs.google.com/spreadsheets/d/1iWCNJcSutYqpULSQHlNyGInUvHg2BoUGoNRIGa6Szc4/edit?usp=sharing) 不能解释数据中所有较新字段，估算值不作为本项目已验证指标。
