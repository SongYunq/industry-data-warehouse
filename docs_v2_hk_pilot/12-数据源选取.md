# 香港先锋数据源选取

- 状态：已确认
- 最后更新：2026-11-12（Asia/Shanghai）

## 选择

新数据源 V2 已有香港、东京、新加坡近一年季度归档。依用户最新安排，首个端到端先锋选香港；本轮不接入东京和新加坡的业务模型和看板。

## 选择理由

- 香港有四个连续季度归档、房源和街区边界文件齐全，适合先贯通文件、模型、Doris 与 Streamlit。
- 单城避免跨城市货币与街区口径比较，缩小首版处理范围。
- 香港四期房源记录数分别为 6,630、2,115、6,734、6,614；该异常差异作为数据质量提示保留，而不是选择性删除某期。

## 范围外

东京和新加坡数据仍保留在原始目录，但不进入本轮先锋仓库。跨城扩展时重新检查货币、房间分类、街区语义和各期覆盖，不因共享字段名而假设口径一致。
