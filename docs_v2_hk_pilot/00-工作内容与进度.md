# 香港先锋工作内容与进度

最后更新：2026-11-12（Asia/Shanghai）

## 当前状态

V2 选择香港作为先锋，已完成从业务边界、扩展星型模型、Doris 物理表，到数据装载代码和 Streamlit 看板首版。模型包含 7 个维度、3 个事实主题；本地汇总核数确认 22,093 条房源事实、344,830 行日历摘要、188 行评论月摘要。`hk_airbnb_pilot` 十张表已建，但 Doris 装载只完成部分第一期数据，仍因 BE 系统可用内存低水位中断。Streamlit 本地模式的八个区块已在浏览器逐项检查。

正式 `docs/` 未改动。阶段设计和证据仅记录在本目录。

## 已确认的数据事实

- 四个快照的详细房源记录数依次为 6,630、2,115、6,734、6,614；2026-03 的低值尚无原因证据。
- 2025-12 与 2026-03 的 `price` 全空；2026-06 有 6,046 条非空，2026-09 有 5,603 条非空。
- 2026-09-20 共 6,614 条唯一房源；非空挂牌价中位数为 475，评分均值为 4.512，可订 365 天字段的中位数为 269 天。
- 以上均是源快照观察值，不是订单、成交或已入住事实。
