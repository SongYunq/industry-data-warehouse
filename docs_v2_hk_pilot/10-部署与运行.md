# 香港先锋部署与运行

- 状态：本地模式可运行；Doris 服务在线但装载受内存低水位限制
- 最后更新：2026-11-12（Asia/Shanghai）

本次启动的本地预览当前在 [http://127.0.0.1:8502](http://127.0.0.1:8502) 运行。8501 端口不可用，因此本次使用 8502；常规启动仍以项目配置端口为准。

## 运行环境

在项目目录运行以下命令；依赖由 Pixi 管理：

```bash
pixi run dashboard
```

默认监听项目配置的本地 Streamlit 地址和端口。看板初次打开优先连接 `127.0.0.1:9030` Doris；若连接失败，默认 `auto` 模式会从已下载香港数据文件加载预览。

## Doris 数据库模式

```bash
pixi run services-up
pixi run data-load-hong-kong
pixi run dashboard
```

专属业务库名：`hk_airbnb_pilot`。当前 DDL 包含 7 个维度表和 3 个事实表；数据写入由程序批量 INSERT 与流式聚合完成，结构由 [DDL](../sql/pilot_hong_kong/001_schema.sql) 定义。

## 模式切换

| 环境变量 | 行为 |
| --- | --- |
| `HK_PILOT_DATA_MODE=auto` | 默认值，先尝试 Doris，失败回退本地 |
| `HK_PILOT_DATA_MODE=warehouse` | 必须使用 Doris；失败时显示连接或表状态错误 |
| `HK_PILOT_DATA_MODE=local` | 仅读本地香港原始 CSV，并流式汇总日历/评论 |

设置环境变量的语法随终端不同；不要把密码写入代码或提交到版本库。Doris 连接参数沿用项目 `.env` 配置。

## 当前环境限制

本次确认 Docker Desktop 与 Doris FE/BE 在线。扩展 DDL 已创建十张表，但装载时 Doris 报系统可用内存约 396 MB，低于分配低水位。当前只有第一期部分记录写入；完整模式不会读取部分数据，会自动回退本地预览。待可用内存恢复后重跑即可，唯一键会覆盖已有自然键。无需清理或重建其他共享服务。
