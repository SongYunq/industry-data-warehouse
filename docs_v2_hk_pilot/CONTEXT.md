# 香港短租挂牌快照

本上下文描述 Inside Airbnb 香港先锋可观察的公开挂牌数据，用于限定课程演示中的业务术语和分析对象。

最后更新：2026-11-12（Asia/Shanghai）

## 语言

**房源（Listing）**：某一期来源快照中出现的一个短租挂牌对象，以 `listing_id` 标识。不要把它称为订单或已入住住宿。

**房源快照（Listing Snapshot）**：一个房源在某个来源采集日期记录到的属性。不要把跨快照缺席直接解释成退市。

**街区（Neighbourhood）**：Inside Airbnb 房源字段或 GeoJSON 提供的区域名称。不要仅凭该名称称为法定行政区。

**房型（Room Type）**：来源提供的整套、独立房间、合住房间或酒店房间类别。

**房屋类型（Property Type）**：来源对具体物业类型的类别描述，例如 rental unit、condo 或 hotel；保留来源分类，不与房型混为一谈。

**房东快照（Host Snapshot）**：某房东在一个来源采集日期公开可见的属性。超赞和身份验证状态只对该快照成立，不代表永久状态。

**挂牌价（Listed Price）**：快照 `price` 字段中的公开报价。不要称为成交价或结算金额。

**可订天数（Availability）**：抓取时未来日期在公开日历中显示为可订的天数。不要称为入住天数或出租率。

**日历可订房态比例（Calendar Availability Share）**：指定快照、日期和挂牌分类组合中，来源标记可订的房态记录占比。不可订可能是预订或房东封锁；不要称为入住率。

**评论月汇总（Monthly Review Summary）**：最新累积评论导出按评论日期月份计算的评论记录数与有评论房源数。评论历史不等于订单，季度累积文件也不能直接相加。
