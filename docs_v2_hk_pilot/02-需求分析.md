# 香港先锋需求与指标口径

- 状态：首版范围已确定；使用者画像未单独调查
- 最后更新：2026-11-12（Asia/Shanghai）

## 目标

用香港作为新数据源的端到端演示，回答三个可由现有快照支持的问题：

1. 每个季度抓取快照中有多少房源记录，房源分布在哪些街区？
2. 房源由哪些房间类型和房屋类型构成？
3. 在存在非空挂牌价的快照中，不同街区和房间类型的挂牌价大致如何分布？
4. 各街区、房型和房屋类型的公开日历可订状态如何随日历日期变化？
5. 最新累积评论文件显示的月度评论活动和房东公开属性分布如何？

首版面向课程项目展示与公开数据观察，不假定特定经营者、房东或政府部门据此采取运营决策。

## 指标定义

| 名称 | 计算方式 | 适用限制 |
| --- | --- | --- |
| 快照房源数 | 同一 `city_key + snapshot_date` 下 `listing_id` 去重计数 | 表示当期来源记录，不等于持续经营房源数；快照缺失不能证明退市 |
| 挂牌价非空率 | `price` 非空房源数 ÷ 当前筛选下房源数 | 仅说明字段覆盖，不做空值填补 |
| 挂牌价中位数 | 对 `price` 非空数值取中位数 | 来源按当地货币记录，香港展示为 HKD；不是成交价。2025-12 与 2026-03 不具备价格值 |
| 平均评分 | 对 `review_scores_rating` 非空值取算术平均 | 仅包含有评分的挂牌；显示口径须同时查看有效样本数 |
| 未来 365 天可订中位数 | 对 `availability_365` 取中位数 | 未来可订状态不区分预订和房东封锁；不是入住天数或出租率 |
| 日历可订房态比例 | 同一快照、日历日期及分类组合下，可订房态数 ÷ 全部状态记录数 | 不可订状态可能是预订或房东封锁；不代表入住率 |
| 月度评论数 | 最新累积 `reviews.csv.gz` 中按评论日期月份计数 | 各期文件不相加；评论不等于订单 |
| 超赞房东房源占比 | 当前筛选房源中 `host_is_superhost=true` 的记录数 ÷ 房源记录数 | 来源快照属性，只表示该期来源标记 |
| 街区房源数 | 当前筛选下按街区对 `listing_id` 去重计数 | 街区边界使用来源 GeoJSON，不能自动等同于政府行政区界 |

## 明确不提供的结论

没有逐笔订单、入住凭证和结算数据，因此不计算实际入住率、实际 ADR、RevPAR、订单成交价或实际收入。来源里的 `estimated_occupancy_l365d`、`estimated_revenue_l365d` 定义尚未复核，且旧版官方字段字典未涵盖，首版不纳入指标。

## 过滤与验收目标

用户可按快照日期、街区、房间类型、房屋类型、房东类型筛选。房源指标、街区/结构图、房东画像和明细共用筛选；日历不按房东类型拆分，评论历史不回连历史房屋属性。页面需显示数据模式、数据来源、价格覆盖率和 2026-03 房源数异常提示。
