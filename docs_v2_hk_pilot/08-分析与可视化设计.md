## 页面结构

| 页面 | 内容与口径 |
| --- | --- |
| 市场概览 | 房源量、非空挂牌价中位数、评分均值和 365 天可订数；展示 2026-03 来源记录量异常 |
| 街区分布 | GeoJSON 边界设色、房源量排行和街区价位/评分摘要；不显示房源点位 |
| 房源结构 | 按房型、房屋类型查看房源数量、挂牌价和评分覆盖 |
| 房东画像 | 房东去重数、超赞房东/身份验证房源占比、房东房源组合；不展示公开房东 ID |
| 可订日历 | 选定快照下按日展示可订房态比例，并列街区汇总；可按街区、房型、房屋类型筛选 |
| 评论趋势 | 从最新一期累积评论文件查看月度评论活动、评论房源数和高值月份 |
| 房源明细 | 所选快照筛选结果的前 500 条房源属性；不显示标识和坐标 |
| 数据口径 | 来源、指标定义、缺失处理及不可推断事项 |

## 交互

全局筛选项为快照日期、街区、房型、房屋类型、房东类型。房源 KPI、街区和结构图、房东画像、明细使用同一套筛选。日历事实只支持快照、街区、房型和房屋类型，因此不跟随房东类型筛选。评论文件没有把历史房源属性逐期关联到评论，评论趋势不跟随房源类别筛选。

## 视觉与数据模式

浅色布局和紫色色阶用于街区数量。Doris 表完整时显示仓库模式；服务不可用或仅部分装载时，页面退回本地源文件，按需流式计算日历与评论摘要，并显示本地预览提示。价格图不补空值；可订图明确标注为房态比例，不称入住率。2026-03 房源数波动只说明来源记录变化。
