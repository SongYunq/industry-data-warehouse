# Inside Airbnb V2 香港先锋工作区

最后更新：2026-11-12（Asia/Shanghai）

本目录记录香港先锋从 V2 数据到 Streamlit 看板的独立设计、实现和运行证据。按用户要求，本目录不挂入正式 `docs/` 索引，也不修改正式阶段文档；以后若要转正，再集中核对并迁移。

## 当前范围

- 城市：香港。
- 快照：2025-12-27、2026-03-29、2026-06-27、2026-09-20。
- 展示目标：房源快照、街区分布、房型与房屋类型、房东快照属性、日历房态和月度评论活动。
- 明确边界：源数据不含订单或结算流水，不计算实际入住率、成交价、ADR、RevPAR 或实际收入。
- 看板具有 Doris 数据仓库和本地原始文件预览两种模式；本地预览会流式汇总日历与评论。
- Doris 专属数据库已建 10 张表；本次重跑因 BE 内存低水位中断，当前只有第一期部分记录。看板需检测完整性并退回本地预览。

## 快速运行

```bash
pixi run dashboard
```

Doris 服务就绪且 BE 有足够可用内存后，将香港房源、维度和摘要事实写入独立数据库 `hk_airbnb_pilot`：

```bash
pixi run services-up
pixi run data-load-hong-kong
pixi run dashboard
```

默认优先读 Doris；连接失败或校验到部分装载时，页面自动退回本地香港 CSV，并在页首说明数据模式。强制本地预览可设 `HK_PILOT_DATA_MODE=local`；强制 Doris 可设为 `warehouse`。四期日历本地聚合约 344,830 行，最新评论按月汇总 188 行。
